# TP842N-V3 打印服务器用户指南

## 快速开始

### 1. 连接设备

1. **电源连接**: 将路由器连接到电源适配器
2. **网络连接**: 用网线连接电脑到 LAN 口
3. **打印机连接**: 将 HP LaserJet 1020 连接到 USB 接口

### 2. 访问管理界面

1. 设置电脑 IP 为自动获取 (DHCP)
2. 打开浏览器访问: `http://192.168.10.1`
3. 使用默认账号登录:
   - 用户名: `admin`
   - 密码: `thdn12345678`

### 3. 配置网络

#### 有线网络
默认已配置 DHCP 自动获取 IP

#### 无线网络
- **SSID**: `THDN-dayin`
- **密码**: `thdn12345678`

## 打印机设置

### 自动检测

1. 连接 HP LaserJet 1020 到 USB 接口
2. 等待 30 秒让系统自动识别
3. 打印机将自动配置并共享

### 手动配置

1. 访问 CUPS 管理界面: `http://192.168.10.1:631`
2. 点击 "Administration" → "Add Printer"
3. 选择 "HP LaserJet 1020"
4. 按照向导完成配置

### 客户端连接

#### Windows
1. 打开 "控制面板" → "设备和打印机"
2. 点击 "添加打印机"
3. 选择 "网络打印机"
4. 输入: `http://192.168.10.1:631/printers/HP-LaserJet-1020`

#### macOS
1. 打开 "系统偏好设置" → "打印机与扫描仪"
2. 点击 "+" 添加打印机
3. 选择 "IP" 标签
4. 地址: `192.168.10.1`
5. 协议: `HP Jetdirect - Socket`
6. 名称: `HP LaserJet 1020`

#### Linux
```bash
# 使用 CUPS 添加打印机
lpadmin -p HP1020 -E -v ipp://192.168.10.1:631/printers/HP-LaserJet-1020
```

## 故障排除

### 无法访问管理界面

1. **检查 IP 设置**:
   ```bash
   # Windows
   ipconfig /all
   
   # macOS/Linux
   ifconfig
   ```

2. **尝试手动设置 IP**:
   - IP: 192.168.10.100
   - 子网掩码: 255.255.255.0
   - 网关: 192.168.10.1

3. **检查网络连接**:
   ```bash
   ping 192.168.10.1
   ```

### 打印机无法识别

1. **检查 USB 连接**:
   - 确认打印机电源开启
   - 更换 USB 线缆
   - 尝试不同的 USB 接口

2. **重启 CUPS 服务**:
   ```bash
   # 通过 SSH 或串口连接
   /etc/init.d/cups-setup restart
   ```

3. **查看系统日志**:
   ```bash
   dmesg | grep -i usb
   dmesg | grep -i printer
   ```

### 打印质量问题

1. **检查打印机状态**:
   - 确保有足够的纸张
   - 检查墨粉/墨盒状态
   - 清洁打印头

2. **更新驱动**:
   - 访问 CUPS 管理界面
   - 检查驱动版本
   - 重新安装驱动

### WiFi 连接问题

1. **信号强度**:
   - 确保路由器位置合适
   - 避免物理障碍
   - 检查天线连接

2. **频道干扰**:
   - 更改 WiFi 频道
   - 使用 WiFi 分析工具
